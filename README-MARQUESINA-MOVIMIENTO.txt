DECOR DESIGN CHIH — MARQUESINA ANIMADA

Se agregó una franja en movimiento debajo del encabezado con:
Plafones, Lámparas, Decoración, Ciudad Juárez, Calidad, Estilo,
Decor Design Chih, Lambrín, Efecto Mármol, Persianas, Panel Walnut y Papel Tapiz.

Características:
- Movimiento continuo y suave.
- Se detiene al pasar el mouse.
- Adaptada para celular.
- Mantiene el estilo negro y dorado.
- No requiere cambios en Supabase.

Para actualizar:
1. Descomprime el ZIP.
2. Sube todos los archivos a GitHub reemplazando los anteriores.
3. Presiona Commit changes.
4. Espera 1–3 minutos.
5. Actualiza la página con Ctrl + F5.

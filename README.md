# Página web de Decor Design

Esta carpeta contiene una página web estática lista para publicarse gratuitamente en GitHub Pages.

## Archivos principales
- `index.html`: contenido de la página.
- `style.css`: colores, diseño y adaptación para celular.
- `script.js`: menú móvil, animaciones y formulario de WhatsApp.
- `assets/images/`: logotipo y fotografías.

## Cómo publicarla gratis en GitHub Pages
1. Entra a GitHub y crea una cuenta.
2. Pulsa **New repository**.
3. Usa un nombre como `decor-design`.
4. Marca el repositorio como **Public**.
5. Entra al repositorio y pulsa **Add file > Upload files**.
6. Sube TODO el contenido de esta carpeta. `index.html` debe quedar en la raíz, no dentro de otra carpeta.
7. Pulsa **Commit changes**.
8. Abre **Settings > Pages**.
9. En **Build and deployment**, selecciona **Deploy from a branch**.
10. Selecciona la rama `main` y la carpeta `/root`, y pulsa **Save**.
11. Espera de 1 a 5 minutos. GitHub mostrará una dirección parecida a:
   `https://TU-USUARIO.github.io/decor-design/`

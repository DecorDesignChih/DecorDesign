DECOR DESIGN — SUBCATEGORÍAS

PRIMERO: SUPABASE
1. Abre Supabase > SQL Editor.
2. Copia todo el archivo 02-supabase-subcategorias.sql.
3. Presiona Run.
4. No borra tus datos actuales.

DESPUÉS: GITHUB
1. Descomprime este ZIP.
2. Sube todos los archivos reemplazando los anteriores.
3. index.html debe quedar en la raíz del repositorio.

EL PANEL AHORA PERMITE
Categorías > Subcategorías > Productos.

Ejemplo:
Lambrín > Lambrín Media Luna > producto, precio e imagen.
Placas PVC > Placas Mate > producto, precio e imagen.
Persianas > Personalizada > producto, precio e imagen.

Vigas y Papel Tapiz aceptan productos directos y después puedes crearles subcategorías desde el panel.

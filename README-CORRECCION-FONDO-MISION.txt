QUÉ SE CORRIGIÓ
- Las cinco fotografías del fondo están incrustadas directamente en index.html.

- Se redujo el tamaño del título para dejar visibles los trabajos.

  • Nuestra misión
  • Nuestra visión
  • Nuestra ubicación

  • Botones de WhatsApp y llamada
- El menú ahora dice “Misión y visión”.

CÓMO ACTUALIZAR
1. Descomprime este ZIP.
2. Sube TODOS los archivos a tu repositorio DecorDesign.
3. Reemplaza los anteriores.
4. Presiona Commit changes.
5. Espera de 1 a 3 minutos.
6. Abre la página y presiona Ctrl + F5.

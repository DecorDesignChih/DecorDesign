DECOR DESIGN — VERSIÓN MULTIDISPOSITIVO

Esta versión está preparada para:
- iPhone y Safari
- Android y Chrome
- iPad y tablets Android
- MacBook y Safari/Chrome
- Windows y Edge/Chrome/Firefox
- Computadoras y pantallas grandes

Cambios incluidos:
- Diseño adaptable a cualquier tamaño de pantalla.
- Compatibilidad con áreas seguras de iPhone y iPad.
- Campos de 16 px para evitar zoom automático en iPhone.
- Menús y botones táctiles.
- Ventanas del panel adaptadas a navegadores móviles.
- Respaldo del CDN de Supabase.
- Mensajes visibles si una conexión falla.
- Compatibilidad con navegadores que no soportan dialog.showModal.
- Compatibilidad con equipos que no soportan crypto.randomUUID.
- Se forzó una versión nueva de CSS y JavaScript para evitar caché viejo.

CÓMO ACTUALIZAR
1. Descomprime el ZIP.
2. Sube todos los archivos y carpetas a GitHub reemplazando los anteriores.
3. Presiona Commit changes.
4. Espera de 1 a 3 minutos.
5. Actualiza con Ctrl + F5 en computadora.
6. En celular, cierra la pestaña y vuelve a abrir el enlace directamente en Safari o Chrome.

No requiere cambios en Supabase.

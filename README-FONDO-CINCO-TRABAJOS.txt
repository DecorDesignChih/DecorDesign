DECOR DESIGN CHIH — FONDO CON LOS CINCO TRABAJOS

CAMBIOS
- Se eliminaron las imágenes anteriores del fondo principal.
- El fondo utiliza únicamente las cinco fotografías enviadas.
- Las fotografías cambian automáticamente cada 5.5 segundos.
- Se agregó transición suave y acercamiento lento.
- En computadora se conserva el trabajo completo sobre un fondo difuminado.
- En celular se utiliza una versión vertical optimizada.
- El logo, el botón con símbolo de WhatsApp, el panel y las fotografías del catálogo se conservaron.
- No requiere ejecutar ningún SQL nuevo en Supabase.

ACTUALIZAR GITHUB
1. Descomprime el ZIP.
2. Sube todos los archivos y la carpeta assets al repositorio DecorDesign.
3. Reemplaza los archivos anteriores.
4. Presiona Commit changes.
5. Espera de 1 a 3 minutos.
6. Abre la página y actualiza con Ctrl + F5.
